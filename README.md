# CZ - Verze

## Mathima
Maturitní projekt – 2D rogue-lite počítačová hra vytvořená v Unity s využitím jazyka C#

---

## O hře
Mathima je 2D top-down rogue-lite hra, ve které hráč bojuje proti nekončícím vlnám nepřátel, sbírá zkušenosti, leveluje a zvyšuje sílu svých útoků. Projekt byl vytvořen jako maturitní práce a obsahuje:

- Automatické útoky (plošné poškození a naváděné střely)
- EXP a levelovací systém
- Postupné zlepšování útoků během hraní
- Jednoduchá AI pro nepřátele
- Vlastní pixel-art grafika vytvořená autorem

# EN - Version

## Mathima
Graduation Project – A 2D rogue-lite video game developed in Unity using C#

---

## About the Game
Mathima is a 2D top-down rogue-lite game where the player fights off endless waves of enemies, gains experience, levels up, and upgrades their attacks. The project was created as part of a graduation thesis and includes:

- Automatic attacks (area damage and homing projectiles)
- Experience and leveling system
- Progressive attack upgrades during gameplay
- Simple enemy AI
- Original pixel art graphics created by the author
